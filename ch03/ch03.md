## Truthy & Falsy

- 참이나 거짓을 의미하지 않는 값도, 조건문 내에서 참이나 거짓으로 평가하는 특징
- 이를 이용하면 조건문을 간결하게 만들 수 있다.

```javascript
if (123) {
  //Truthy. 참 같은 값
  console.log("123 is truthy");
} else {
  //Falsy. 거짓 같은 값
  console.log("123 is falsy");
}

if (undefined) {
  //Falsy. 거짓 같은 값
  console.log("undefined is truthy");
} else {
  //Truthy. 참 같은 값
  console.log("undefined is falsy");
}
```

### Falsy한 값

```javascript
let f1 = undefined;
let f2 = null;
let f3 = 0;
let f4 = -0;
let f5 = NaN; //Not a Number
let f6 = ""; //빈 문자열
let f7 = 0n; //BigInteger

if (!f1 && !f2 && !f3 && !f4 && !f5 && !f6 && !f7) {
  console.log("All values are falsy");
}
```

### Truthy한 값

7가지 Falsy한 값을 제외한 나머지 모든 값

```javascript
let t1 = "hello";
let t2 = 123;
let t3 = []; //Array
let t4 = {}; //Object
let t5 = function () {}; //Function
let t6 = () => {}; //Arrow Function
let t7 = Symbol("symbol"); //Symbol
let t8 = BigInt(123); //BigInteger

if (t1 && t2 && t3 && t4 && t5 && t6 && t7 && t8) {
  console.log("All values are truthy");
}
```

### 활용 사례

```javascript
function printName(person) {
  if (!person) {
    console.log("Person의 값이 없음");
    return;
  }
  console.log(person.name);
}

let person; //undefined
printName(person); //Person의 값이 없음
```

printName 내에서 조건을 `if (person == undefined || person == null)`와 같은 방식으로 설정하려면, 모든 Falsy한 값을 체크해야 한다. 하지만, `if (!person)`로 조건 설정 시 한 번에 조건 체크가 가능하다.

## 단락 평가(Short-circuit Evaluation)

- 논리 연산자 `&&`와 `||`를 사용해 조건을 간결하게 평가하는 방식.
- 동적 타이핑 언어의 특징이다.
- `&&`는 첫 번째 Falsy 값을 반환하거나, 모든 값이 Truthy면 마지막 값을 반환.
- `||`는 첫 번째 Truthy 값을 반환하거나, 모든 값이 Falsy면 마지막 값을 반환.

```javascript
function returnFalse() {
  console.log("False Function");
  return false;
}

function returnTrue() {
  console.log("True Function");
  return true;
}

console.log(returnFalse() && returnTrue()); // returnTrue는 실행되지 않음
console.log(returnTrue() && returnFalse()); // 둘 다 실행됨

console.log(returnTrue() || returnFalse()); // returnFalse는 실행되지 않음
console.log(returnFalse() || returnTrue()); // 둘 다 실행됨
```

### 단락 평가 활용 사례: validation

```javascript
function printName(person) {
  const name = person && person.name;
  console.log(name || "이름이 없음");
}

printName(); // 이름이 없음
printName({ name: "John" }); // John
```

## 구조 분해 할당

### 배열의 구조 분해 할당

```javascript
let arr = [1, 2, 3];

let [one, two, three, four = "기본값"] = arr;
// console.log(one, two, three, four); // 1 2 3 undefined
```

### 객체의 구조 분해 할당

```javascript
let person = {
  name: "홍길동",
  age: 30,
  hobby: "독서",
};

let { name, age: myAge, hobby, job = "프로그래머" } = person;
// console.log(name, myAge, hobby, job); // 홍길동 30 독서 프로그래머
```

### 객체 구조 분해 할당을 이용해서 함수의 매개변수를 받는 방법

```javascript
const func = ({ name, age, hobby, extra }) => {
  console.log(name, age, hobby, extra); // 홍길동 30 독서 undefined
};
func(person); //객체를 매개변수로 전달해야 한다.
```

## Spread 연산자

- Spread: 흩뿌리다, 펼치다 라는 뜻.
- 배열이나 객체에 저장된 여러 개의 값을 펼쳐서 새로운 배열이나 객체를 만드는 데 사용됨.
- 배열이나 객체를 복사하거나 결합할 때 유용하다.

```javascript
let arr1 = [1, 2, 3];
let arr2 = [4, ...arr1, 5, 6];
// console.log(arr2); // [4, 1, 2, 3, 5, 6]

let obj1 = { a: 1, b: 2 };
let obj2 = { ...obj1, c: 3, d: 4 };
// console.log(obj2); // { a: 1, b: 2, c: 3, d: 4 }

function funcA(p1, p2, p3) {
  console.log(p1, p2, p3);
}
funcA(...arr1); //1 2 3
```

## Rest 매개변수

- Rest: 나머지라는 뜻.
- 매개변수에 ...을 붙이면 나머지 매개변수로 사용됨.
- 배열로 전달됨.
- 반드시 마지막에 위치해야 함.

```javascript
function funcB(p1, p2, ...rest) {
  console.log(p1, p2, rest);
}
let arr3 = [1, 2, 3, 4, 5];
funcB(...arr3); // 1 2 [3, 4, 5]
funcB(...[1, 2, 3]); // 1 2 3
funcB(...[1]); // 1 undefined []
```

## 원시타입 vs 객체타입

- 원시타입 : string, number, boolean, null, undefined, symbol
- 객체타입 : object, array, function
- 원시타입은 메모리에서 값이 복사(Call by Value) vs 객체타입은 메모리에서 주소가 복사(Call by Reference, 얕은 복사)
- 원시타입은 메모리에서 스택에 저장 vs 객체타입은 힙에 저장
- 원시타입은 불변(메모리 값 수정 X) vs 객체타입은 가변(메모리 값 수정 O)
- **객체를 복사하려면, 스프레드 연산자로 프로퍼티만 따로 복사하여 객체를 새로 생성하는 방식으로 복사해야 한다. (깊은 복사)**

### 객체 타입 주의사항 1: 의도치 않게 값이 수정될 수 있다.

```javascript
let o1 = { name: "John" };
```

#### 얕은 복사

- 객체의 참조값을 복사함
- 원본 객체가 수정될 수 있어 위험함

```javascript
let o2 = o1; //o1과 o2는 같은 객체를 참조한다.
o2.name = "Jane"; //o2의 name을 수정하면 o1의 name도 수정된다.
// console.log(o1.name); // Jane
// console.log(o2.name); // Jane
```

#### 깊은 복사

- 새로운 객체를 생성하면서 프로퍼티만 따로 복사 함
- 원본 객체가 수정될 일이 없어 안전함

```javascript
let o3 = { ...o1 }; //o1을 복사하여 o3를 생성한다.
o3.name = "John"; //o3의 name을 수정해도 o1의 name은 수정되지 않는다.
// console.log(o1.name); // Jane
// console.log(o3.name); // John
```

### 객체 타입 주의사항 2: 객체간의 비교는 기본적으로 참조값을 기준으로 이루어진다.

```javascript
o1 = { name: "John" };
o2 = o1;
o3 = { name: "Tom" };
o4 = { name: "Tom" };
```

#### 얕은 비교

- 참조값을 기준으로 비교함

```javascript
o1 === o2; // true
o3 === o4; // false
```

#### 깊은 비교

- 객체를 문자열로 변환하여 비교
- JSON.stringify() 등의 내장 함수를 이용해야 함

```javascript
JSON.stringify(o1) == JSON.stringify(o2); // true
JSON.stringify(o2) == JSON.stringify(o3); // false
JSON.stringify(o3) == JSON.stringify(o4); // true
```

### 객체 타입 주의사항 3: 배열과 함수도 사실 객체다

## 순회(iteration)

- 배열, 객체에 저장된 여러개의 값에 순서대로 하나씩 접근하는 것

### 배열 순회

```javascript
let arr = [1, 2, 3];
```

#### 배열 인덱스를 이용한 순회

```javascript
for (let i = 0; i < arr.length; i++) {
  // console.log(arr[i]);
}
```

#### for of 문을 이용한 순회

```javascript
for (let item of arr) {
  // console.log(item);
}
```

### 객체 순회

```javascript
let person = {
  name: "John",
  age: 20,
  hobby: "Reading Books",
};
```

#### Object.keys()를 이용한 순회

- Object.keys(): 객체의 키를 배열로 반환

```javascript
let keys = Object.keys(person); // ['name', 'age', 'hobby']
for (let key of keys) {
  const value = person[key];
  // console.log(key, value); // 키, 값 출력
}
```

#### Object.values()를 이용한 순회

- Object.values(): 객체의 값을 배열로 반환

```javascript
let values = Object.values(person); // ['John', 20, 'Reading Books']
for (let value of values) {
  // console.log(value); // 값만 출력
}
```

### for in 문을 이용한 순회

- for of 문과 for in 문을 헷갈리면 안됨
  - for in: 객체 순회
  - for of: 배열 순회

```javascript
for (let key in person) {
  const value = person[key];
  // console.log(key, value); // 키, 값 출력
}
```
